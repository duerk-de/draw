- Draws data points from a table.
- Points, lines and splines are supported.
- Focusses on high quality / accuracy drawing of data using standard normal distribution (Gauss).
- Additive points result in great colors.
- Fully customizable by parsing and executing functions. Those Functions can change position, color and size of data points at any time.
- Still quite fast :-)
